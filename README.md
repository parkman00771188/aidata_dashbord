# AI Hub + 공공데이터포털 통합 데이터 카탈로그

AI Hub 데이터셋(975건)과 공공데이터포털 파일데이터(약 84,000건)를 한 화면에서 검색·비교하고,
**Gemini에게 목적을 설명하면 필요한 데이터를 추천받는** 로컬 대시보드입니다.

```text
대시보드 실행.bat          # http://localhost:8765 통합 화면
데이터 갱신.bat            # AI Hub + 공공데이터 목록/상세 메타데이터 갱신
공공데이터 전체 수집.bat   # 남은 데이터 미리보기까지 전체 수집/재개
스냅샷 내보내기.bat        # 깃에 올릴 수 있는 크기로 카탈로그 내보내기
수집완료시 깃 업로드.bat   # 수집이 끝나면 스냅샷 만들어 GitHub에 자동 커밋·푸시
```

> 처음 clone 했다면 `대시보드 실행.bat` 만 실행하면 됩니다.
> `data/catalog.db` 가 없으면 깃에 포함된 스냅샷에서 **자동으로 복원**한 뒤 서버가 뜹니다.

## 1. 화면 구성

### 통합 / AI Hub / 공공데이터포털 탭
- **분야 필터**: 네모 칩을 눌러 **여러 개 동시 선택**(공공행정 + 보건의료 …). `전체`로 해제.
- **제공 방식 컬럼**: 데이터를 실제로 받을 수 있는지 표에서 바로 구분합니다.

  | 배지 | 뜻 |
  |---|---|
  | `↓ 다운로드` | AI Hub: 신청 후 내려받기 가능(866건) · 공공데이터: 포털에서 파일 다운로드 |
  | `↓ 다운로드 (승인)` | AI Hub 개별 승인 절차가 필요한 데이터 |
  | `🔒 안심존` | AI Hub 안심존 데이터(109건). 이용신청 후 **열람만** 가능, 다운로드 불가 |
  | `↗ 기관 제공` | 공공데이터: 제공기관 자체 사이트에서 다운로드 |
  | `↗ 오프라인` | 전자기록매체로만 제공 |

  AI Hub 행에는 용량(예: 228 GB)도 함께 표시됩니다.
- 검색어/형식/미리보기 필터, 열 정렬, 페이지네이션(25·50·100·200)은 모두 **서버에서** 처리하므로
  8만 건이어도 브라우저가 느려지지 않습니다.
- ★ 를 누르면 **내 데이터**에 담기고 `data/my_datasets.json` 에 저장됩니다.

### 상세 패널 — 출처별로 탭 구성이 다릅니다
| 출처 | 탭 |
|---|---|
| **AI Hub** | 개요(소개·구축목적·제공정보·기본정보·구축업체·AI 성능) / 메타데이터 구조표 / 데이터 통계 / 어노테이션·데이터 구조 / 활용 AI 모델 / 데이터 성능 / 저작도구 / 구축 업체 / 변경 이력 |
| **공공데이터포털** | 개요(설명·핵심정보) / 파일데이터 정보(기본·제공정보 전체) / 데이터 항목(컬럼) / 미리보기(행 샘플) |

### ✦ AI 추천 탭
화면 하단의 **"어떤 주제에 필요한 데이터가 필요하신가요?"** 바를 누르면 열립니다.

1. 목적을 문장으로 입력 — 예) *"청소년 우울증 조기선별 모델을 만들고 싶습니다"*
2. Gemini가 **검색 키워드**를 뽑고 → 로컬 카탈로그 84,933건에서 후보 60건을 찾아 →
   목적에 맞는 데이터만 골라 이유·활용법을 정리합니다. (지어낸 데이터가 섞이지 않도록
   **카탈로그에 실제 존재하는 uid만** 통과시킵니다.)
   - 후보를 넘길 때 **실제 데이터 항목(컬럼 이름)** 을 함께 전달합니다. 그래서 데이터명이
     그럴듯해도 필요한 값이 항목에 없으면 걸러지고, 추천의 `활용 항목`은 **추정이 아니라
     실제 컬럼명**입니다. 데이터끼리 결합할 **연결키**(공통 항목)도 함께 제시합니다.
   - 항목 색인은 공공데이터 미리보기 헤더와 AI Hub 메타데이터 구조표에서 만들며
     현재 **61,661건**(공공 60,874 · AI Hub 787)을 담고 있습니다. 검색어도 항목명에 매칭됩니다.

**검색 방식 (질문에 맞는 데이터를 놓치지 않기)**
- **FTS5 trigram 색인**을 씁니다. 한국어 부분일치가 되고 3글자 이상 키워드는 **1ms 이하**로 찾습니다.
  (전체 스캔 방식일 때 0.41초 → 0.001초, 약 400배)
- 빨라진 만큼 **키워드를 16~22개**까지 넉넉히 만듭니다. 동의어·표기 변형(전기차/전기자동차/친환경차,
  충전소/충전기/충전시설)과 기관명(정신건강복지센터 등)을 함께 넣어 개념이 통째로 빠지지 않게 합니다.
- 흔한 낱말('등록', '위치')은 **IDF로 가중치를 낮춰** 정밀도를 지킵니다.
- **키워드마다 상위 30건을 반드시 확보**하고, 종합 점수 상위 220건과 합쳐 후보를 만듭니다.
- 질문에서 뽑은 토큰은 **조사를 떼어**('입지를'→'입지') 보조 검색어로 최대 6개만 씁니다.
- 같은 질문은 **키워드를 캐시**(`data/keyword_cache.json`)해 재검색 결과가 흔들리지 않습니다.
  (Gemini는 temperature 0에서도 키워드가 매번 달라져 결과가 바뀌는 원인이었습니다.)
- 검색은 보통 **0.1~1.5초**, 결과 하단 회색 줄에 *매칭 N건 → 정밀검토 M건 → 후보 60건* 이 표시됩니다.
- 색인은 서버 시작·스냅샷 복원 시 자동 생성됩니다(`item_search` + `search_fts`, 약 40초).
3. 결과 구성
   - **필요한 기능** — 목적 달성에 필요한 기능과 각 기능에 필요한 데이터 항목
   - **추천 데이터** — 핵심/보조/참고로 묶어서, 출처·분야·제공방식 배지 + 왜 필요한지 + 활용 방법 +
     활용할 컬럼 + **원문 주소** + `상세`(패널 열기) / `담기`(내 데이터) 버튼
   - **활용 흐름** — 단계마다 *어떤 데이터의 어떤 항목을 어떤 키로 결합해* 무엇을 만드는지와
     그 단계의 **결과물**을 적습니다. 사용한 데이터는 칩으로 표시되고 눌러서 상세를 볼 수 있습니다.
     마지막에 **"이렇게 하면 무엇을 할 수 있나"** 로 최종적으로 답할 수 있는 질문·만들 수 있는 것을 정리합니다.
   - **🔒 안심존 이용 계획** — 추천에 안심존 데이터(다운로드 불가)가 섞이면 자동으로 추가됩니다.
     `docs/안심존 사용 방법.md` 의 운영 규칙을 AI에게 함께 주어, 다운로드 가능한 데이터로 밖에서
     코드를 먼저 검증하고 안심존에서는 학습만 하도록 **역할을 나눈 계획**을 만듭니다.
     들어가기 전 준비(IRB·멀티데이터 동시 신청 등) / 안심존 안에서의 순서(인터넷 5일 → 마운트 → 차단) /
     반출 가능한 결과물(소스코드·모델 파일만) / 30일 일정표 / 안심존 특유 주의점을 함께 제시합니다.
     카드 안에서 **안심존 사용자 매뉴얼 PDF**를 바로 내려받을 수 있습니다.
   - **유의사항**, **추가로 확보하면 좋은 데이터**
4. 맨 아래에 **사용한 토큰과 예상 비용**이 흐릿한 회색 한 줄로 표시됩니다.
   예) `이 추천에 토큰 15,224개 사용 (입력 11,308 · 출력 3,916 중 사고 1,248 · 호출 2회) · 예상 비용 $0.0132 (약 ₩19)`
   - 토큰 수는 Gemini 응답의 `usageMetadata` 실측값입니다(사고 토큰도 출력으로 과금되므로 합산).
   - 금액은 `ai_service.py` 의 `PRICING` 표 기준 **추정치**입니다. 표에 없는 모델은 같은 등급
     (pro/flash/flash-lite) 단가로 추정하며, 마우스를 올리면 적용된 단가가 보입니다.
     공개 단가가 바뀌면 `PRICING` 과 `USD_KRW` 만 고치면 됩니다.
5. 결과는 **자동 저장**되어 왼쪽 "저장된 추천" 목록에서 다시 볼 수 있습니다
   (`data/recommendations.json`). `?reco=<id>` 로 바로 열 수도 있습니다.

### AI 설정 (오른쪽 위 ⚙)
- **Gemini API 키**: [Google AI Studio](https://aistudio.google.com/apikey)에서 발급.
  키를 입력하고 포커스를 옮기면 바로 저장되고 모델 목록을 불러옵니다.
- **모델**: 계정에서 실제 쓸 수 있는 모델을 **API에서 그대로 가져와** 세대별로 묶어 보여줍니다.
  - 정렬은 버전 숫자를 비교해 **항상 최신 세대가 맨 위**입니다(모델명을 코드에 박아두지 않으므로
    구글이 새 세대를 내면 새로고침만 해도 바로 위에 뜹니다).
  - `항상 최신 (별칭)` 그룹의 `gemini-flash-latest` / `gemini-pro-latest` 는 구글이 최신 모델로
    자동 연결해 주는 별칭이라 손대지 않아도 계속 최신을 씁니다. (새 설치 기본값 = `gemini-flash-latest`)
  - 이미지·음악·음성·임베딩·로보틱스 모델은 JSON 텍스트 출력을 못 하므로 목록에서 제외합니다.
  - 도움말의 **"최신 모델(...)로 맞추기"** 를 누르면 한 번에 최신으로 바뀝니다.
  - 목록에 없는 신규 모델은 **"목록에 없는 모델 직접 입력"** 으로 ID를 적어 바로 쓸 수 있습니다.
- 키는 **이 PC의 `data/settings.json` 에만** 저장되고 브라우저로 다시 내려보내지 않으며
  `.gitignore` 로 깃에서 제외됩니다.

## 2. 깃 업로드 방식 (용량 문제 해결)

`data/catalog.db` 는 원본 HTML·미리보기 본문까지 담고 있어 **400MB 이상**이라 그대로 올릴 수 없습니다
(GitHub 파일 상한 100MB). 그래서 **스냅샷 방식**을 씁니다.

| | 크기 | 깃 |
|---|---|---|
| `data/catalog.db` | 약 400MB | ❌ 제외 |
| `raw/` (원본 HTML 캐시) | 수백 MB | ❌ 제외 |
| `data/settings.json` (API 키) | – | ❌ 제외 |
| **`data/snapshot/items-*.jsonl.gz`** | **약 123MB (4파트)** | ✅ 커밋 |
| `data/datasets.json`, `data/details/` | 약 38MB | ✅ 커밋 |

```bash
python snapshot.py export    # catalog.db  -> data/snapshot/*.jsonl.gz (파트당 38MB 이하로 분할)
python snapshot.py restore   # 스냅샷      -> catalog.db 재생성
python snapshot.py info      # 현재 상태 확인
```

- 스냅샷에는 목록·분야·기관·형식·설명·상세정보와 **미리보기 전체(컬럼명 + 샘플 행 200만 행)** 가
  모두 들어갑니다. 즉 `catalog.db` 를 그대로 되살릴 수 있습니다. 제외되는 것은 재수집 가능한
  원본 HTML 캐시(`raw/`)뿐입니다.
- 복원 시 데이터 항목 색인과 검색 색인(FTS)이 자동으로 다시 만들어집니다(복원 약 90초).
- 데이터를 갱신한 뒤에는 `스냅샷 내보내기.bat` 을 한 번 실행하고 커밋하세요.

### 수집이 끝나면 자동으로 깃에 올리기
```bash
python publish_when_done.py              # 수집 완료를 기다렸다가 스냅샷 생성 + 커밋 + 푸시
python publish_when_done.py --now        # 기다리지 않고 지금 바로
python publish_when_done.py --no-push    # 커밋까지만
```
완료 판정은 ① 미리보기 대기(pending) 0건, 또는 ② 수집기 프로세스가 없고 20분간 진행이 없을 때입니다.
5분마다 진행률·속도·예상 시간을 출력합니다.

> 스냅샷은 압축 파일이라 **커밋할 때마다 저장소 기록이 약 30MB씩 늘어납니다.**
> 수집이 끝난 뒤 한 번만 올리는 것을 권장합니다.

## 3. 파일 구성

| 경로 | 설명 |
|---|---|
| `catalog.html` | 통합 대시보드(목록·상세·내 데이터·AI 추천·설정) |
| `serve.py` | 로컬 서버 + API. 루트에서 `catalog.html` 제공 |
| `ai_service.py` | Gemini 호출, 로컬 후보 검색, 추천 생성/보관 |
| `snapshot.py` | 카탈로그 스냅샷 내보내기/복원 |
| `catalog_db.py` | 통합 SQLite 스키마와 AI Hub 동기화 |
| `crawl_aihub.py` | AI Hub 목록·상세 수집기 |
| `crawl_data_go_kr.py` | 공공데이터포털 목록·상세·미리보기 수집기 |
| `data/catalog.db` | 검색·필터·상세·미리보기 DB (깃 제외, 스냅샷에서 복원) |
| `data/snapshot/` | 깃에 올리는 카탈로그 스냅샷 |
| `item_columns` 테이블 | 데이터 항목(컬럼) 색인. 스냅샷 복원·서버 시작 시 자동 생성 |
| `data/datasets.json`, `data/details/<sn>.json` | AI Hub 목록·상세 원본 |
| `data/my_datasets.json` | ★로 담은 내 데이터 |
| `data/recommendations.json` | 저장된 AI 추천 |
| `data/settings.json` | Gemini API 키·모델 (깃 제외) |
| `index.html` | 기존 AI Hub 전용 대시보드(보존) |
| `docs/안심존 사용 방법.md` | 안심존 이용·반출 절차 정리. AI 추천의 안심존 계획 근거 |

### 서버 API
| 엔드포인트 | 설명 |
|---|---|
| `GET /api/catalog/list` | `source`, `q`, `field`(다중), `format`, `preview`, `page`, `per`, `sort`, `dir` |
| `GET /api/catalog/detail?uid=` | 출처별 상세 + `access`(제공 방식) |
| `GET /api/catalog/facets` | 분야·형식 집계 |
| `GET /api/catalog/stats` | 출처별 건수, AI Hub 제공방식 집계 |
| `GET·POST /api/my` | 내 데이터 |
| `GET·POST /api/settings` | Gemini 키(마스킹 반환)·모델 |
| `GET /api/ai/models` | 사용 가능한 Gemini 모델 목록 |
| `POST /api/ai/recommend` | `{query}` → 추천 생성 + 저장 |
| `GET /api/recommendations`, `POST /api/recommendations/delete` | 추천 보관함 |

## 4. 수집기 사용법

```bash
pip install requests beautifulsoup4

# AI Hub
python crawl_aihub.py                # 전체 수집(캐시 사용) + JSON 생성
python crawl_aihub.py --refresh      # 목록 갱신 + 새 항목만 수집
python crawl_aihub.py --parse        # 재수집 없이 다시 파싱
```
